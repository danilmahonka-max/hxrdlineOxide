# hxrdlineOxide
Android WebView demo with HXRDLINE six-digit activation UI.
GitHub Actions builds a debug APK on push to main or manual dispatch. Download it from the workflow run Artifacts.

## Demo key warning
Contains 300 sample keys (100 each for 1, 7, and 14 days). The list and local activation state are inside the APK and can be extracted or modified. This is not secure production licensing. Strong licensing requires server-side one-time redemption, rate limiting, signed device-bound tokens, and server-side expiry/revocation checks.
